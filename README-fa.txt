نسخه نهایی پرسشنامه EMA باز شدن پنجره

تغییرات:
- تصویر پنجره به صفحه آغاز پرسشنامه اضافه شد.
- نام تصویر به window-open.png تغییر کرد.
- کش CSS و JavaScript با version query به‌روزرسانی شد.
- پاسخ «خیر» و «مطمئن نیستم» دیگر صفحه موفقیت کاذب نشان نمی‌دهد و رویداد را برای پاسخ فرد دیگر باز نگه می‌دارد.
- تغییر پاسخ جریان هوا فوراً مراحل و دکمه‌های Wizard را به‌روز می‌کند.
- کنترل بارگذاری cloud-survey.js اضافه شد.
- فایل JavaScript از نظر Syntax بررسی شد.

فایل‌های survey-config.js و cloud-survey.js باید مثل قبل کنار این فایل‌ها قرار بگیرند.
